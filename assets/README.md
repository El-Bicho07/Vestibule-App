# Assets

Place these image files in this directory before publishing the Expo app:

- `icon.png` — 1024×1024 app icon
- `splash.png` — splash screen artwork (any aspect ratio, centered)
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `favicon.png` — 48×48 web favicon

For local development with Expo Go, these are optional. The app will boot without them, though `expo-cli` may print a warning.
